Helmet Classification & Violation System

An intelligent traffic surveillance pipeline designed to detect motorcycles, localize riders, and classify helmet compliance across dense multi-vehicle road environments. The system differentiates compliant riders (Driver Helmet) from violators (Driver No Helmet) while maintaining a live violation counter and frame-level telemetry.

Hierarchical Entity Detection

Simultaneously detects motorcycles (Bike), riders (Driver), and head-region helmet states in crowded traffic.

Automated Violation Counter

Flags non-helmeted riders with distinct red bounding boxes and increments the active violation log in real time.

Live Telemetry & Tracking

Integrates object ID assignment, frame indexing, timestamping, and live FPS monitoring for video stream evaluation.
